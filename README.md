# Data Analytics Challenges

This repository contains practical data analytics challenges and solutions.

The objective is to solve real-world and analytical problems using different data analytics tools and compare different approaches to solving the same problem.

## Tools & Technologies

- Microsoft Excel – Dynamic Array Formulas
- Power Query
- Python in Excel
- Python with Jupyter Notebook

## Approach

For each challenge, I try to solve the problem using multiple approaches where applicable.

This helps demonstrate:

- Problem-solving and analytical thinking
- Advanced Excel skills
- Data transformation using Power Query
- Python-based data analysis
- Comparison of different analytical approaches
- Practical application of data analytics tools

## Challenges

New challenges and solutions will be added regularly.

Each challenge may include one or more solutions using:

- Excel Dynamic Arrays
- Power Query
- Python in Excel
- Python with Jupyter Notebook
